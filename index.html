Features

Everything you need to reverse-engineer great design

One URL becomes a complete, browsable breakdown of what makes a site's interface work.

Color extraction

Pull the exact palette a site uses — primary, accent, background and supporting tones — with copyable hex values.

Typography mapping

See the display and body typefaces in use, plus a rebuilt type scale you can reference for your own projects.

Component breakdown

Buttons, inputs, cards, nav and footer patterns, itemized with their shape, radius and spacing rules.

Faithful code reconstruction

Rebuild the rendered DOM with computed visual styles — no screenshot required.

Favorites library

Save any extraction to revisit later. Build a personal archive of interfaces you find worth studying.

Code library

Every saved favorite keeps its generated markup and styles organized in one searchable table.
